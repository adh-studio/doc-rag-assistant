ASSISTANT DOCUMENTAIRE

doc-rag-assistant

Un pipeline RAG (Retrieval-Augmented Generation) qui repond a des questions sur un corpus de documents en citant systematiquement ses sources. Fonctionne 100% hors ligne grace a un repli TF-IDF deterministe.

Le pipeline en cinq etapes

ETAPE 1
Ingestion
Lecture des documents et decoupage en chunks qui se recouvrent.
→
ETAPE 2
Embeddings
Vectorisation de chaque chunk (TF-IDF local ou API distante).
→
ETAPE 3
Index vectoriel
Stockage numpy persiste, cosinus par produit scalaire.
→
ETAPE 4
Recherche top-k
Les passages les plus proches de la question, filtres par score.
→
ETAPE 5
Generation citee
Reponse via CLI claude ou repli extractif, sources citees.

Choix d'architecture

Deux modes d'embeddings

Fournisseur distant si une cle API est presente, sinon repli TF-IDF local et deterministe. Meme interface, zero couplage.

Base vectorielle interchangeable

Implementation numpy simple, remplacable par FAISS, pgvector ou Chroma sans toucher au reste du pipeline.

Generation en chaine

CLI claude en priorite, repli extractif deterministe en secours. Une reponse est toujours produite.

Garde-fou anti-hallucination

Sous un seuil de similarite, l'assistant repond honnetement "je ne sais pas" plutot que d'inventer.

Utilisation

# Indexer un dossier de documents
python -m rag ingest corpus

# Poser une question (la reponse cite ses sources)
python -m rag ask "Combien coute la formule Business ?"
